# Approved product images

Place repository-safe, publicly uploadable product images in this directory and register every file in `../asset-manifest.md`.

Recommended starting set when available:

| Suggested role | Suggested filename | Typical use |
| --- | --- | --- |
| Transparent square logo | `logo-transparent-512.png` | Logo and avatar fields |
| Dark-background square logo | `logo-dark-512.png` | Dark previews where the transparent logo loses contrast |
| Social or listing cover | `01-social-cover-1200x630.png` | Social cards and directory galleries |
| Product example | `02-product-example.png` | Truthful output or product example |
| Workflow or feature image | `03-workflow.png` | Explaining how the product works |
| Use-case image | `04-use-cases.png` | Showing supported audiences or uses |

The filenames are recommendations, not mandatory fields. Do not add empty placeholder binaries. For each actual image, record dimensions, bytes, MIME type, source, upload permission, caption or alt text, and crop constraints in the asset manifest.
