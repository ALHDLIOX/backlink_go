# Approved product screenshots

Place current, repository-safe screenshots in this directory and register every file in `../asset-manifest.md`.

For each screenshot, document:

- public page or product build captured;
- capture date;
- feature or step shown;
- whether sample content is fictional or demonstrative;
- approved caption or alt text;
- public-upload scope;
- any crop, redaction, or size limitation.

Before committing a screenshot, inspect it for private user data, account names, email addresses, tokens, private URLs, browser-session details, customer content, and third-party material without reuse permission. Redaction must not change the meaning of the interface or evidence.

Suggested naming uses a stable display order and a short purpose, for example:

```text
01-onboarding.png
02-main-workflow.png
03-result.png
```
